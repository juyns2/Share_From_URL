Bậc Thang Số

Tách N thành bậc thang 1 + 2 + … + n cộng phần dư, phân loại bậc thang và dùng chuỗi UCLN để tìm ước của N (N = p·q).

Thử nhiều số

Cách đọc

  • Bậc thang tròn: N = T(n) = n(n+1)/2, dư 0. Ước nằm trong n và n+1.
  • Thiếu 1: dư = n, tức N = T(n+1) − 1 = n(n+3)/2. Ước nằm trong n và n+3.
  • Bậc thang nâng k: N = (k+1) + (k+2) + … + (k+m) = m(m+2k+1)/2, tức N − T(m) chia hết cho m. k = 1, 2, 3… ứng với “đơn, đôi, ba”: thừa số thứ hai là m+3, m+5, m+7…
  • Chuỗi UCLN: g = UCLN(N, dư); nếu g = 1 (hoặc g = N) thì cộng thêm bậc trên cùng n, rồi n−1, … cho tới khi g là ước thật.
